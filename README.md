# Tools

A collection of developer tools and utilities.

## Contents

### [Claude Speaks](./claude-speaks/)

High-quality text-to-speech CLI for Apple Silicon using MLX-Audio. Lets Claude (or any application) vocalize text with natural-sounding AI voices.

- Daemon architecture for instant response
- 10 voice presets (American/British)
- Native MLX performance on Apple Silicon
